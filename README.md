# CB2330 - Scientific Computing for the Life Sciences

The exercise notebooks live here, one folder per session, and the Colab badge beside each
one opens it in a runtime that already has everything installed. Everything else about the
course - slides, videos, deadlines - is in Canvas.

Once Colab opens, we save a copy to Drive first: **File > Save a copy in Drive**. A Colab
runtime is disposable, and work that isn't saved to our own Drive disappears with it.

I rebuild these notebooks during the term, so a fresh click on the badge is better than
reopening a copy from three weeks ago.
